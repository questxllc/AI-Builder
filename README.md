# Bilang Ride

A counting game for early learners (ages 4–5) in the Philippines, built as an AI Builder project for XPRIZE with AI.

- One `index.html` file with its CSS and JavaScript inside it, and no outside libraries
- Works on phones
- Five games: counting, finding numbers, more or fewer, matching numbers to groups, and adding
- Three levels: Seed (1–5), Sprout (1–10) and Tree (1–20)
- An AI tutor that estimates each child's mastery and adapts the games to it
- Voice in English or Filipino, using the browser's built-in speech

To change the words, objects, places or stickers, edit the `CONTENT` block near the top of the script in `index.html`.
